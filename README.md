Nxt Trendz is an e-commerce application inspired by platforms like Amazon and Flipkart. Users can securely log in and browse products with search, filtering, and sorting functionality.

Key Features
Implemented dedicated Login, Products, and Product Details pages using React Router.
Built reusable React components using props, state, lists, event handlers, and form inputs.
Implemented JWT-based authentication and authorization using a login POST API.
Persisted the authenticated user's JWT token in localStorage.
Sent the JWT token in the Authorization header for subsequent protected API requests.
Implemented product search, filtering, and sorting using query parameters.
Integrated REST APIs using the Fetch API.
Built a responsive interface using CSS and Bootstrap.

Nxt Trendz is a React-based e-commerce application inspired by Amazon and Flipkart. I implemented authentication using a login REST API and JWT. After successful login, I persisted the JWT in localStorage and attached it to subsequent API requests through the Authorization header. I implemented protected routing for the Products and Product Details pages, along with product search, filtering, and sorting using query parameters. I also structured the application using reusable React components and separated API and authentication logic into service modules
